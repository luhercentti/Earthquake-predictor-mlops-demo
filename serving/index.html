🌍 Earthquake Forecast

Probabilistic forecasting based on USGS + IGP Peru seismic catalog (1973–present)

⏳ First query of the day may take 12–15 minutes. This app runs on Render's free tier, which shuts down after inactivity and must restart + download the model before responding. Subsequent queries in the same session are fast (~5 s).
How this works

This tool uses a LightGBM model trained on ~1 million historical earthquakes to estimate which zones are most likely to experience the next earthquake, and how strong it might be. It does not predict exact dates — that is physically impossible with current science.

Country / City — the region to forecast. Any country, city, or US state.
Search radius — how far around a city centre to search (cities only). Default 200 km.
Only zones with recent M≥X — hides quiet zones. Useful for large countries with hundreds of active cells. Leave blank to show all zones.
Results to show — number of top-ranked zones returned. Top 1 = the single most likely next location.
⚠ The model only contains events M≥2.5. Setting "Only zones with recent M≥X" below 2.5 will return no results.
